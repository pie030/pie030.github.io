02 / Design decisions

Less geometry.
More structure.

The revision focused on the things a viewer should recognize immediately: a roof that actually closes, trees with supporting branches, and water that follows the land.

01 / Construction

Build believable objects.

Roof panels have thickness and gable closure. Doors and windows occupy actual openings. The bridge has a walkable-looking deck and supported railings. This is visual construction, not yet a gameplay collision system.

02 / Natural forms

Connect every part.

Tree canopies are supported by trunks and branches. The creek has a recessed bed, banks and one downstream waterfall. Rocks use faceted silhouettes rather than repeated generic cubes.

03 / Optimization

Keep the silhouette.

Geometry was reduced from 32,685 to 15,582 triangles (about 52% fewer), while retaining the main scene elements. Four modular exports preserve the same origin for assembly.

03 / Technical notes

Built through iteration.

The base geometry was generated with Python geometry tools and subsequently refined in Blender. The exported model was inspected through renders and structural checks.

The full scene was exported as GLB and re-imported for automated geometry checks. The latest export converts the authored Z-up geometry to the glTF Y-up convention for consistent glTF file exchange.

All screenshots on this page are renders of the actual model. The exported asset is available below for inspection.
